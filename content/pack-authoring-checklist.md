# Pack Authoring Checklist

- Unique pack key and immutable version.
- Supported manifest/schema version and locale.
- Unique question keys and option keys.
- Exactly one correct option for single-choice items.
- Valid taxonomy, difficulty, cognitive objective and perspective tags.
- Clear explanation and factual provenance/source date where needed.
- Usage rights and review metadata recorded.
- No executable HTML or sensitive personal data.
- JSON schema and semantic checks pass.
- Human review complete; staging preview approved; checksum verified.
