## AI architecture boundary

**AI is development-only.** It supports internal requirements analysis, architecture, code assistance, test generation, security review and offline content-authoring. The deployed learner application has no LLM calls, agent runtime, MCP server, vector database or AI-token dependency. Published questions and explanations are human-approved immutable content; learner personalization is deterministic and profile/session-rule based. See ADR-006 and the AI development workflow.
